## ⚠️ The Higher Education Challenge (Problem Statement)

Modern Indian universities face rigorous regulatory demands that legacy enterprise systems fail to solve:

1. **AICTE 75% Attendance Directives:** Over 2.8 million technical students across India face end-semester exam disqualification ("detention") because attendance deficits are calculated post-mortem at semester-end without proactive margin warnings.
2. **UGC 2023 Statutory 48-Hour SLA Redressal:** Federal regulations mandate a time-stamped 48-hour resolution clock for student grievances; yet 85% of campuses still handle complaints via physical paper files.
3. **NEP 2020 Multidisciplinary Credit Mobility:** The National Education Policy requires automated credit accumulation via the Academic Bank of Credits (ABC / Digilocker), requiring uniform schema alignment.
4. **Ballooning Cloud API Costs ($12/student/year):** Modern campus apps attempt to use external LLMs (OpenAI, AWS), creating unsustainable recurring token bills for tier-2/3 institutions.
5. **Classroom Disconnect & External App Leakage:** Online and hybrid lectures routinely redirect students to external browser windows (Zoom, Meet, Jitsi), breaking attendance tracking and live doubt buffers.
